# NotchOTP

[English](../README.md) · [Проверки и сборки](https://github.com/Photon94/NotchOTP/actions/workflows/ci.yml)

Нативное приложение для macOS: OTP-коды в компактной панели под чёлкой.
Версия 0.2: ширина совпадает с чёлкой; панель плавно вытекает вниз и втягивается при закрытии.
Первая локальная версия, SwiftUI + AppKit, без внешних библиотек и сетевых запросов.

## Начало работы

[**Скачать NotchOTP 0.2.0 для Apple Silicon**](https://github.com/Photon94/NotchOTP/releases/tag/v0.2.0). Также можно собрать приложение по инструкции ниже.

Сборка без нотарификации Apple. Если macOS заблокирует первое открытие, используйте [инструкцию Apple для приложения, которому вы доверяете](https://support.apple.com/en-us/102445).

1. Распакуйте `NotchOTP.zip` и перенесите `NotchOTP.app` в папку «Программы».
2. Откройте приложение. В строке меню появится значок ключа.
3. Нажмите «Добавить» и введите название аккаунта и секретный ключ Base32 из настроек двухфакторной аутентификации сервиса.
4. Или нажмите «QR из файла», выберите изображение одного QR-кода и подтвердите название аккаунта.
5. Нажмите **Control + Option + Space** — появятся код и таймер.

В первой версии добавление QR выполняется из файла, без камеры и захвата экрана.
Секретный ключ — не одноразовый шестизначный код, а ключ настройки, который выдаёт сервис.
Не удаляйте прежний способ входа до проверки кодов нового приложения.

## Клавиши

| Действие | Клавиши |
|---|---|
| Вызвать / скрыть панель | Control + Option + Space |
| Следующий / предыдущий аккаунт | Tab / Shift + Tab |
| Найти аккаунт | Начните печатать или Command + F |
| Выбрать результат | Стрелки вверх / вниз |
| Скопировать и закрыть | Enter или Command + C |
| Закрыть | Escape |
| Настройки | Значок ключа → «Аккаунты и настройки…» |

Для смены глобального сочетания нажмите на него в настройках и введите новое.
Нужен хотя бы один модификатор: Control, Option или Command. Escape отменяет запись.
Клик по коду также копирует его. Панель появляется на экране с курсором.
На мониторе без чёлки панель расположена под строкой меню.
Приложение продолжает работать после закрытия окна настроек. Выход — через значок ключа.

## Данные

Все аккаунты и секреты сохраняются в связке ключей macOS; в настройках на диске хранится
только глобальное сочетание. Ключи не отправляются по сети. TOTP: SHA1/SHA256/SHA512,
6 или 8 цифр, период 1–3600 секунд. HOTP, Steam Guard и пакетный перенос Google не поддерживаются.
Коды зависят от правильного системного времени.

Копирование помечено как конфиденциальное и локальное; буфер очищается после истечения кода
(не позднее 30 секунд), только если с тех пор в него ничего не скопировано. Сторонние менеджеры
буфера могут не соблюдать эти пометки. В интерфейсе нет экспорта секретов.

## Сборка

Откройте `Package.swift` в Xcode либо выполните в папке исходников:

```sh
swift test
./scripts/build.sh
open dist/NotchOTP.app
```

Сборка предназначена для архитектуры Mac, на котором выполняется команда.
Первоначальная локальная версия проверена на Apple Silicon и macOS 26.5; минимальная цель сборки — macOS 13.
Это локально подписанная сборка без Developer ID и нотарификации Apple.
При пересборке macOS может повторно запросить доступ к сохранённой записи связки ключей.
Для распространения другим пользователям потребуется стабильная подпись Developer ID.

Тесты связки ключей по умолчанию пропущены: они создают и удаляют отдельную запись с публичным
тестовым ключом. Запуск: `NOTCHOTP_KEYCHAIN_TESTS=1 swift test`.

Демо, не читающее и не изменяющее хранилище:

```sh
open dist/NotchOTP.app --args --demo
```

Перед запуском демо завершите обычный экземпляр, чтобы не занимать одно сочетание двумя процессами.
