Релиз с подписью Developer ID и нотарификацией Apple. Код приложения не менялся — изменился только способ сборки и распространения.

### Что изменилось

- Приложение и образ DMG подписаны сертификатом **Developer ID Application** с защищённой средой выполнения (hardened runtime) и меткой времени Apple.
- Обе загрузки нотарифицированы Apple, тикет вложен (stapled), поэтому Gatekeeper проверяет их без обращения к сети.
- Первый запуск больше не требует обходных действий из инструкции Apple. macOS по-прежнему один раз спрашивает подтверждение для программы, загруженной из интернета.
- Релизный workflow больше не перезаписывает уже опубликованный релиз собственной ad-hoc-сборкой.

### Установка

1. Скачайте **NotchOTP-v0.2.1-macOS-arm64.dmg** ниже и откройте его.
2. Перетащите **NotchOTP.app** на ярлык «Программы». Также доступен ZIP.
3. Откройте приложение, добавьте аккаунт и нажмите **Control + Option + Space**.

Если версия 0.2.0 уже установлена, замените её — аккаунты хранятся в связке ключей macOS и сохранятся. При первом запуске новой подписи macOS один раз запросит доступ к существующей записи связки ключей.

**Требования:** Mac с Apple Silicon (M1 и новее), macOS 13 или новее. Интерфейс на русском.

**Ограничения:** нет HOTP, Steam Guard, пакетного переноса Google Authenticator, синхронизации и экспорта ключей. Сохраните прежний способ входа до проверки новых кодов.

Файл `SHA256SUMS.txt` содержит контрольные суммы ZIP и DMG. Проверить подпись после установки: `codesign -dv --verbose=4 /Applications/NotchOTP.app` и `spctl --assess --type execute /Applications/NotchOTP.app`.

**English:** Distribution release. The application is unchanged; the downloads are now signed with a Developer ID Application certificate under hardened runtime and notarized by Apple, with tickets stapled to both the app and the disk image, so Gatekeeper clears them on first launch without the per-app override. Upgrading from 0.2.0 keeps existing accounts in the macOS Keychain; the new signature prompts once for access to the stored record. Requires macOS 13+ on Apple Silicon. Russian UI. See [SHA256SUMS.txt](https://github.com/Photon94/NotchOTP/releases/tag/v0.2.1) for checksums and the [README](https://github.com/Photon94/NotchOTP#readme) for setup and limitations.
