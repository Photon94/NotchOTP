# NotchOTP 0.3.1 — Six interface languages

The interface now supports **English, Russian, Simplified Chinese, German, French, and Hindi**. This includes the notch panel, settings, native menus, setup forms, tooltips, and app error messages.

Open **Accounts and Settings → Language** to switch instantly. By default, NotchOTP uses the first supported language in your macOS preferences, falling back to English. Account names, keys, and OTP digits stay unchanged.

The app and DMG are Developer ID signed and notarized by Apple, with stapled tickets. Requires an Apple Silicon Mac running macOS 13 or later. Quit your existing version, open the DMG, and drag NotchOTP into Applications to replace it.

## Русский

Теперь доступны шесть языков: **русский, английский, упрощённый китайский, немецкий, французский и хинди**. Переключение — в **«Аккаунты и настройки…» → «Язык»**, без перезапуска. Выбор сохраняется. Аккаунты, ключи и цифры одноразовых кодов не меняются.

DMG подписан сертификатом разработчика и прошёл нотарификацию Apple.
