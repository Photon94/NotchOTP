Первый публичный релиз **NotchOTP** — нативного TOTP-аутентификатора для macOS.

### Что умеет

- Компактная панель по ширине чёлки с плавным открытием и закрытием.
- OTP-код и круговой таймер до обновления.
- Настраиваемое глобальное сочетание, переключение аккаунтов и поиск с клавиатуры.
- Добавление аккаунтов по секретному ключу, ссылке `otpauth://` или QR-коду из изображения.
- Локальное хранение в связке ключей macOS; без сети и аналитики.

### Установка

1. Скачайте **NotchOTP-v0.2.0-macOS-arm64.zip** ниже.
2. Распакуйте архив и перенесите **NotchOTP.app** в «Программы».
3. Откройте приложение, добавьте аккаунт и нажмите **Control + Option + Space**.

**Требования:** Mac с Apple Silicon (M1 и новее), macOS 13 или новее. Интерфейс на русском. Сборка проверяется на macOS 15; первоначальная локальная версия проверена на macOS 26.5.

**Подпись:** сборка подписана локально (ad hoc), без Developer ID и нотарификации Apple. macOS может заблокировать первый запуск. Если вы доверяете этой сборке, используйте способ открытия конкретного приложения из [инструкции Apple](https://support.apple.com/en-us/102445); не отключайте Gatekeeper целиком.

**Ограничения:** нет HOTP, Steam Guard, пакетного переноса Google Authenticator, синхронизации и экспорта ключей. Сохраните прежний способ входа до проверки новых кодов.

Файл `SHA256SUMS.txt` содержит контрольную сумму архива. Исходники привязаны к тегу `v0.2.0`.
